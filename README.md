# CookiePad

A Cookie Clicker addon that adds touch-friendly controls for playing on iPad and other touch devices without a keyboard.

## Features

- **D-pad overlay** (bottom-right corner): Sends arrow key events for navigating menus/upgrades.
- **Hover mode button** (center of D-pad, 👆): Tap it, then tap any element on the page to trigger its tooltip instead of clicking it. Automatically deactivates after one use.

## Usage

Load as a Cookie Clicker mod:

```javascript
Game.LoadMod('https://rolfbjarne.github.io/cookiepad/cookiepad.js');
```

```javascript
javascript:Game.LoadMod('https://rolfbjarne.github.io/cookiepad/cookiepad.js');
```

Or paste the contents of `cookiepad.js` into the browser console.
